# Drawings (Excalidraw)

**Drawings** uses **Excalidraw** to create sketches, wireframes, or visual notes on an infinite canvas.

## Key Features
- **Freehand drawing** with a mouse, trackpad, or stylus.
- **Shapes, arrows, and text** in a hand-drawn sketch style.
- **Images**: insert JPEG, PNG, WebP, or SVG.
- **Infinite canvas** for big ideas.

## Canvas Menu

The Excalidraw menu on the canvas contains:
- **Reset the canvas**: clears the canvas.
- **Export image...**: saves an image.
- **Canvas background**: changes the background color.
- **Save to...**: saves a file.
- **Help**: a list of Excalidraw shortcuts.

The theme follows the app's **Settings → Appearance**.

## Images in Drawings

- On Cloud, Self-host, and CLI, images are compressed and then uploaded to storage. The original file can be at most 5 MB; SVG at most 1 MB. See [Image Upload](../cloud-storage/upload-feature.md).
- In the Desktop app, images are saved directly inside the Drawing file, without storage.

## Team Access

- Creator, Manager, and Editor can edit a Drawing.
- Commenter and Viewer open a Drawing in view-only mode.
- Comments on Drawing objects are not available. Use the **Discussions** tab to discuss a Drawing. See [Comments & Discussions](../collaboration/comments-discussions.md).

## Use Cases
Use Drawings for:
- Creating application wireframes.
- Sketching high-level system architecture.
- Mind mapping or visual brainstorming sessions.
