# Drawings (Excalidraw)

The **Drawings** feature is powered by **Excalidraw**, giving you complete freedom to sketch, create interface mockups, or any visual notes on an infinite canvas.

## Key Features
- **Freehand Drawing**: Draw freely using your cursor or stylus.
- **Library Shapes**: A collection of customizable, ready-to-use shapes.
- **Collaboration Style**: Hand-sketched appearance that feels professional yet casual.
- **Unlimited Canvas**: A vast workspace for your big ideas.

## Usage
Use the Drawings module to:
- Create application *wireframes*.
- Sketch high-level system architecture.
- *Mind mapping* or visual *brainstorming* sessions.
