# Search & Filter

Use **Search** to quickly find Projects and files in the active workspace.

## Opening Search

- Click **Search** in the sidebar, or
- press `⌘K` (macOS) / `Ctrl+K` (Windows and Linux).

The search dialog opens with the *Search files and projects* field. Press `Esc` to close it. Search is disabled while the connection to the server is lost.

## How It Works

- Type at least 2 characters (at most 100).
- Search matches **Project names and file titles**, not document content.
- Results are sorted newest first, up to 5 per type and 20 in total.
- Files in Trash are not searched.

## Type Filter

Select **Filter** to narrow the results:

- **All**
- **Projects**
- **ERD Builder**
- **DB Client** (Desktop/CLI)
- **Notes**
- **Flowcharts**
- **Drawings**

## Scope

| Workspace | What is searched |
| :--- | :--- |
| **Personal** | Your personal files and Projects |
| **Team** | All files in Projects owned by that Team |
| **Desktop and CLI** | All your local files |

To search another workspace, switch to it first with the switcher in the sidebar.

## Tips
- You do not need to type the full name. `user` finds `users_table`, `user_flowchart`, and the `User_Module` Project.
- Select the **Notes** filter, then type a keyword to search documentation without diagrams mixed in.
