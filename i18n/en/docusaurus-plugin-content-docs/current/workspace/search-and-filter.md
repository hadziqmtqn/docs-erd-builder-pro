# Search & Filter

Finding files among dozens of projects can be time-consuming. ERD Builder Pro provides a fast search feature and an intelligent filter system to help you navigate the workspace efficiently.

## Real-time Search
The search feature can be accessed directly via the search bar at the top of the sidebar.
- **Speed**: Results appear in *real-time* as soon as you start typing the first character.
- **Scope**: The system will look for matches in **File Name** and **Project Name**.

## Filter by Document Type
If you want to focus on one type of work, you can use the category filter buttons. This is very useful when a single project contains many mixed files.

Available filters include:
- **ERD Diagrams**: Shows all database schema designs.
- **Flowcharts**: Shows all logic flow diagrams.
- **Notes**: Shows all text documentation (Tiptap).
- **Drawings**: Shows all free-form design sketches (Excalidraw).

## Quick Navigation Tips
1. **Use Short Keywords**: You don't need to type the full name. Typing `user` will bring up `users_table`, `user_flowchart`, and the `User_Module` project.
2. **Combine Filters**: Activate the **Notes** filter then type a keyword to search for specific documentation without being disturbed by diagram files.
3. **Visual Feedback**: Files that match the search criteria will remain visible in the sidebar, while non-matching files will be temporarily hidden.
