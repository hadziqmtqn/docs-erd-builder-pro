# Trash System

ERD Builder Pro memiliki sistem keamanan berlapis untuk mencegah kehilangan data yang tidak disengaja melalui fitur **Trash**.

## Cara Kerja Penghapusan
Saat Anda menghapus sebuah file (Diagram, Note, atau Drawing):
1. File tidak langsung hilang secara permanen.
2. File dipindahkan ke folder **Trash**.
3. File di dalam Trash tidak akan muncul di daftar proyek utama.

## Memulihkan File (Restore)
Jika Anda berubah pikiran:
1. Masuk ke menu **Trash** di sidebar dashboard.
2. Pilih file yang ingin dikembalikan.
3. Klik tombol **Restore**. File akan kembali ke proyek asalnya.

## Penghapusan Permanen
Untuk benar-benar menghapus file dan membersihkan ruang penyimpanan (terutama aset gambar di R2):
1. Masuk ke menu **Trash**.
2. Klik **Delete Permanently**. 
3. **Peringatan**: Tindakan ini tidak dapat dibatalkan.
