# Project Organization

Manajemen proyek yang rapi adalah kunci efisiensi dalam ERD Builder Pro. Anda dapat mengelompokkan berbagai jenis dokumen ke dalam satu unit proyek.

## Konsep Proyek
Satu proyek dalam workspace Anda dapat berisi campuran berbagai tipe file:
- Satu atau lebih **ERD Diagram**.
- **Notes** untuk dokumentasi teknis.
- **Drawings** untuk flowchart arsitektur.

## Cara Mengelola Proyek
- **Membuat Proyek**: Gunakan tombol "New Project" di dashboard utama.
- **Memindahkan File**: Anda dapat memindahkan file antar proyek melalui menu pengaturan file.
- **Status Proyek**: Proyek membantu Anda memisahkan pekerjaan antara satu klien/aplikasi dengan aplikasi lainnya.
