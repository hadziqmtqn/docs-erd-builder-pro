# Search & Filter

Seiring bertambahnya jumlah proyek, fitur pencarian akan memudahkan Anda menemukan dokumen dengan cepat.

## Pencarian Global
Anda dapat menggunakan bilah pencarian di bagian atas dashboard untuk mencari:
- Nama file diagram.
- Judul catatan (Notes).
- Nama proyek.

## Filter Berdasarkan Tipe
Anda dapat mempersempit daftar file dengan memfilter berdasarkan kategori:
- **Diagrams**: Hanya menampilkan ERD.
- **Notes**: Hanya menampilkan dokumen teks.
- **Drawings**: Hanya menampilkan diagram alir/gambar.

Fitur ini membantu Anda tetap fokus pada jenis pekerjaan yang sedang dilakukan.
