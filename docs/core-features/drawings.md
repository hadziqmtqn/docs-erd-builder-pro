# Drawings (Excalidraw)

**Drawings** memakai **Excalidraw** untuk membuat sketsa, wireframe, atau catatan visual di kanvas tanpa batas.

## Fitur Utama
- **Gambar bebas** dengan mouse, trackpad, atau stylus.
- **Bentuk, panah, dan teks** bergaya sketsa tangan.
- **Gambar**: sisipkan JPEG, PNG, WebP, atau SVG.
- **Kanvas tanpa batas** untuk ide besar.

## Menu Kanvas

Menu Excalidraw di kanvas berisi:
- **Reset the canvas**: mengosongkan kanvas.
- **Export image...**: menyimpan gambar.
- **Canvas background**: mengganti warna latar.
- **Save to...**: menyimpan file.
- **Help**: daftar shortcut Excalidraw.

Tema mengikuti **Settings → Appearance** aplikasi.

## Gambar di Drawings

- Di Cloud, Self-host, dan CLI, gambar dikompresi lalu diunggah ke storage. Ukuran awal maksimal 5 MB; SVG maksimal 1 MB. Lihat [Unggah Gambar](../cloud-storage/upload-feature.md).
- Di aplikasi Desktop, gambar disimpan langsung di dalam file Drawing tanpa storage.

## Akses di Team

- Creator, Manager, dan Editor dapat mengedit Drawing.
- Commenter dan Viewer membuka Drawing dalam mode lihat saja.
- Komentar pada objek Drawing tidak tersedia. Gunakan tab **Discussions** untuk membahas Drawing. Lihat [Komentar & Diskusi](../collaboration/comments-discussions.md).

## Kegunaan
Gunakan Drawings untuk:
- Membuat *wireframe* aplikasi.
- Sketsa arsitektur sistem tingkat tinggi.
- *Mind mapping* atau sesi *brainstorming* visual.
