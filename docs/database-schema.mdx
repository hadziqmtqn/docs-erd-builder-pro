# Database Schema

Halaman ini menyajikan struktur database ERD Builder Pro secara visual. Diagram di bawah ini merepresentasikan tabel-tabel utama yang tersimpan di database PostgreSQL (mode **Supabase**) serta bagaimana data tersebut saling terhubung.

## Visualisasi Struktur Database

Gunakan diagram interaktif di bawah ini untuk memahami alur data antar tabel. Anda dapat menggeser tabel atau melakukan zoom untuk melihat detail kolom.

## Kode SQL (DDL) Lengkap

Bagi para pengembang yang ingin melakukan instalasi mandiri atau migrasi database, silakan gunakan skema SQL lengkap di bawah ini:

<details>
<summary>Lihat Seluruh Skema SQL (Supabase)</summary>

```sql
-- Supabase Schema for ERD Builder Pro

-- Projects Table
CREATE TABLE IF NOT EXISTS projects (
  id BIGSERIAL PRIMARY KEY,
  uid UUID DEFAULT gen_random_uuid() UNIQUE,
  name TEXT NOT NULL,
  user_id UUID REFERENCES auth.users(id) ON DELETE SET NULL,
  is_deleted BOOLEAN DEFAULT FALSE,
  deleted_at TIMESTAMPTZ DEFAULT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  is_public BOOLEAN DEFAULT FALSE,
  share_token TEXT,
  expiry_date TIMESTAMPTZ
);

-- Diagrams Table (ERD Files)
CREATE TABLE IF NOT EXISTS diagrams (
  id BIGSERIAL PRIMARY KEY,
  uid UUID DEFAULT gen_random_uuid() UNIQUE,
  name TEXT NOT NULL,
  user_id UUID REFERENCES auth.users(id) ON DELETE SET NULL,
  project_id BIGINT REFERENCES projects(id) ON DELETE SET NULL,
  is_deleted BOOLEAN DEFAULT FALSE,
  deleted_at TIMESTAMPTZ DEFAULT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  viewport_x FLOAT DEFAULT 0,
  viewport_y FLOAT DEFAULT 0,
  viewport_zoom FLOAT DEFAULT 1.0,
  is_public BOOLEAN DEFAULT FALSE,
  share_token TEXT,
  expiry_date TIMESTAMPTZ,
  published_at TIMESTAMPTZ,
  _version INTEGER DEFAULT 0
);

-- [Data tabel lainnya...]
-- Detail lengkap dapat ditemukan di file supabase_schema.sql pada repositori utama.
```

</details>

### Ringkasan Tabel Utama:
*   **`projects`**: Kontainer utama untuk semua file.
*   **`diagrams`**: Tabel induk untuk file ERD.
*   **`entities`**: Menyimpan tabel-tabel individu di dalam diagram.
*   **`columns`**: Menyimpan field/kolom dari setiap entity.
*   **`relationships`**: Menyimpan garis relasi antar tabel.
*   **`entity_changes`**: Sistem Audit Trail untuk riwayat versi (Snapshot).
